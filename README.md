# Job Portal Application

## 🚀 Features
- User & Recruiter roles
- Job posting (Recruiter)
- Job application (User)
- Application status (Selected / Rejected / Reviewed)
- Resume upload (PDF)
- Recruiter can view/download resumes
- Secure recruiter access using invitation code

## 🛠 Tech Stack
- Frontend: React (Vite)
- Backend: Spring Boot
- Database: MongoDB
- Authentication: JWT

## ▶️ Run Locally

### Backend
cd backend
mvn spring-boot:run

### Frontend
cd frontend
npm install
npm run dev
